# Un Ftor pour tous

La carte collaborative des iftars : une carte pour trouver un iftar pendant le Ramadan, ou en signaler un. Projet d'Al Maydan.

**Maquette.** `index.html` montre le principe avec des exemples fictifs autour de Paris : heure du coucher du soleil, liste et carte des iftars, filtres (ce soir, sur place, à emporter, places libres, familles, accessibilité), bouton « Je viens » et formulaire « Proposer un iftar ». Rien n'est enregistré.

Site : https://sleepingroomer.github.io/unftorpourtous/

Carte : Leaflet et fonds de carte OpenStreetMap / CARTO.
